## Decisões estratégicas

1. **Disclaimer = entidade versionada, não constante** — mudança de
   escopo aprovada pelo Luciano durante a sessão (commit `c3e14fb`).
   Permite SUPER_ADMIN editar texto sem deploy, ADMIN sobrescrever por
   tenant, rastro jurídico via FK no recibo (recuperação de texto exato
   mesmo após edições futuras).

2. **Override do tenant SOBRE global** (mesmo padrão `ModeloDocumento`,
   `PlanoContas`) — `cooperativaId String?` no model; null = global,
   valor = override.

3. **Histórico imutável** — `ativo=false` em vez de DELETE. Recibos
   antigos preservam texto via `ResgateRecibo.disclaimerSaqueId` →
   `DisclaimerSaque.texto`.

4. **Versão auto-gerada server-side** — `v{seq}-{data}` (global) ou
   `tenant-v{seq}-{data}` (override). Cliente envia só texto novo.

5. **FK é vínculo autoritativo do aceite** — não a string `versao`.
   Anti-staleness reage à edição do admin entre GET e POST.

6. **Plain text + `whitespace-pre-line`** — sem markdown, sem HTML.
   Defense-in-depth contra XSS no v1.
