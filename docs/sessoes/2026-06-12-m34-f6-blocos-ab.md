### Bloco B — Service + 5 endpoints + DTOs + 34 specs (`b3251f5`)

**Service (`cooper-token.service.ts`, +729 linhas)**:

- `gerarNumeroRecibo(tx, cooperativaId)` — upsert atômico em `ResgateReciboCounter` + increment → `RES-{YYYY}-{NNNNN}` sequencial POR COOPERATIVA (decisão Q3)
- `solicitarResgate(params)` — 4 guards (estabelecimento+pixChave; PIN fora da tx via `PinCooperadoService.validarPinComLockout`; tier ALTO `valor>R$50` exige OTP via `OtpDesafioService.validarOuLancar` motivo `TOKEN_TRANSACAO_STEP_UP`; `assertLimite` sobre TOTAL F2.5). Idempotência por `clientRequestId @unique` (anti-IDOR cross-tenant retorna NotFound genérica). Tx Serializable: re-snapshot saldo + gera numeroRecibo + bloqueia (disp -=qtd, bloq +=qtd conservando invariante) + cria `ResgateRecibo` PENDENTE_APROVACAO_COOP
- `aprovarResgate(params)` — **REFORÇO 3**: `updateMany` compare-and-swap PENDENTE→APROVADO_PIX_DISPARADO (count=1 obrigatório) → dispara `AsaasPixOutService.transferir`. Se status='ERROR': estorno imediato + status FALHA_PIX + BadRequest
- `recusarResgate(params)` — motivoRecusa obrigatório (mín 3 chars) + compare-and-swap → RECUSADO + estorno auditável
- `cancelarResgate(params)` — anti-IDOR via `cooperadoEstabelecimentoId` + compare-and-swap → CANCELADO + estorno. Corrida com aprovação retorna BadRequest claro
- `processarWebhookResgate(params)` — **REFORÇO 2**: verifica `ultimoWebhookEventId` (skip silencioso se duplicado, registra primeiro eventId no swap). **REFORÇO 3**: compare-and-swap APROVADO→PAGO_RECIBO_EMITIDO (sucesso: queima `saldoBloqueadoResgate -= qtd` + `totalResgatado += qtd` + ledger DEBITO `RESGATE_PIX`) OU APROVADO→FALHA_PIX (estorno auditável)
- `estornarResgateInterno(privado)` — devolve tokens bloqueado→disponível em tx Serializable + cria ledger CREDITO `ESTORNO_RESGATE_PIX`. **NUNCA apaga registros** (REFORÇO 1 trilha auditável). Tolera invariante reaplicada (log warn + skip se já estornado)
- `listarResgatesPendentes(params)` — filtros status (default PENDENTE_APROVACAO_COOP), valor mín/máx, datas, paginação
